# n8n Node Reference Lab

## What this repo contains
- `n8n_node_reference.md` — Reference table with 11 analyzed n8n nodes
- `lab_summary.md` — Summary paragraph with key learnings
- `screenshots/` — Folder with node configuration and JSON screenshots

## How to read this
Open `n8n_node_reference.md` to see the full node analysis table.
Each node includes its parameters, settings, what it does, and JSON examples
extracted from two real workflows: `simple_email.json` and `Simple_Agent.json`.
